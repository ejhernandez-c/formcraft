# Formcraft — Frontend

React + TypeScript + Vite + Tailwind CSS + shadcn/ui. See the repository root
[`README.md`](../README.md) for how to run the full stack, and
[`docs/ARCHITECTURE.md`](../docs/ARCHITECTURE.md) §3 for the project structure
and conventions.

## Scripts

| Command                           | Purpose                             |
| --------------------------------- | ----------------------------------- |
| `npm run dev`                     | Start the Vite dev server           |
| `npm run build`                   | Type-check and build for production |
| `npm run lint`                    | ESLint                              |
| `npm run format` / `format:check` | Prettier                            |
| `npm run typecheck`               | TypeScript, no emit                 |
| `npm run test`                    | Vitest                              |
